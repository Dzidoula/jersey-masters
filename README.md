# Jersey Masters

Boutique fictive de maillots de football africains : un projet de démonstration axé sur le design et les animations.

## Fonctionnalités
- Carrousel de 8 maillots (Maroc, Sénégal, Tunisie, Cap-Vert, Nigeria, Ghana, Afrique du Sud, Cameroun) avec thème de couleur dynamique
- Choix de la taille, ajout au panier, favoris, notifications (toasts)
- Panier latéral avec quantités et total, sauvegardé dans le navigateur
- Modale « Tous nos maillots africains »
- Navigation clavier (← →), balayage tactile, responsive, `prefers-reduced-motion`

## Lancer
Aucune dépendance : ouvrez `index.html`, ou servez le dossier (`python3 -m http.server`).

## Notes
HTML, CSS et JavaScript purs. Les maillots sont des illustrations SVG originales (sans logos de fédérations) et les prix sont fictifs.
